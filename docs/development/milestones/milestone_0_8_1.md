## Overview

A patch release in the sense of the [Release Checklist](../release_checklist.md): no new user-facing feature, fixes that protect data capture and the correctness of analysis, and safer defaults. It keeps the v0.8.0 database schema (plus one column and two indexes) and is cut **before** the [ADR-0033](../../adr/0033-unified-naming-and-global-identifiers.md) rename, which belongs to v0.9.0.

This milestone was written after the work was done, to bring the roadmap back in line with the repository.

---

## Phase 1: Analysis Correctness (BirdNET)

**Goal:** Every second of audio is analysed, with the species list of the right season.

### Tasks

- [x] Analyse the last second of each segment (end-aligned tail window)
- [x] Filter species by the week of each recording, not the week the worker started
- [x] Refuse audio that is not at 48 kHz instead of analysing it with scaled-wrong windows; raw-only profiles must record at 48 kHz (ADR-0011)
- [x] Analyse calls across segment boundaries (seam window over contiguous segments)

---

## Phase 2: Recording Timestamps

**Goal:** A segment's name tells when its first sample was recorded, and whether the clock could be trusted.

### Tasks

- [x] Name each segment after its first sample (file mtime minus WAV duration), not its promotion time
- [x] Report the clock sync state (`adjtimex`) in log and heartbeat
- [x] Mark segments named with an unsynchronised clock (`_unsynced`, `recordings.clock_unsynced`) — [Issue 002](../issues/002-ntp-time-jump.md)

---

## Phase 3: Processor & Controller

**Goal:** Cycle cost stays flat as data accumulates; infrastructure hiccups do not stop recording.

### Tasks

- [x] Indexer: known-file cache, batched existence query, path indexes
- [x] Indexer: commit each recording on its own, so one bad file does not roll back the others
- [x] Controller: a missing or erroneous heartbeat is tolerated for the stale timeout before the Recorder is replaced — [Issue 006](../issues/006-controller-adopts-unhealthy-recorders.md)
- [x] Controller: heartbeat age measured on its monotonic clock, so an NTP step neither evicts live Recorders nor hides a hung one

---

## Phase 4: Resource & Security Defaults

**Goal:** The Recorder is the last process the OOM killer takes, and nothing but the Gateway listens on the network.

### Tasks

- [x] OOM order under rootless Podman: Tier 1 at 300, workers at 500; the Recorder reports its effective value (ADR-0020 §2.3)
- [x] Database, Redis and service APIs bind to `127.0.0.1` (`SILVASONIC_INTERNAL_BIND_ADDRESS`)
- [x] Per-installation Gateway login generated by `just setup`; no shared default password
- [ ] Smoke tests log in to the Gateway with a test credential (fix exists, not yet on the release line)

**Goal:** `main` equals `origin/main`, CI is green, and a station can be updated to v0.8.1.

### Tasks
